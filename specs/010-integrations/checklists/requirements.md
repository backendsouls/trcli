## Notes

- Items marked incomplete require spec updates before `/speckit-clarify` or `/speckit-plan`
- Validated in one pass on 2026-10-08; all items pass.
- The spec is authored as parts in `spec-src/`; `spec.md` is generated by
  `scripts/build-spec.sh` and must not be edited directly. CLI contracts are in
  `contracts/`, one file per command group.
- "No implementation details" passes with a deliberate exception: Google Drive and signing
  in with a Google account are named because the request names them as the concrete
  integration. Protocol-level detail (scopes, flows, token lifetimes) is kept out of the
  spec and recorded in `notes/google-sign-in.md` with sources.
- The question in the request — whether sync directly through Google sign-in is possible —
  was checked against Google's documentation on 2026-10-08: yes. Three points in the notes
  remain unverified and are listed there.
- No [NEEDS CLARIFICATION] markers were used. Choices to confirm with `/speckit-clarify`:
  - Sync is for one researcher's own machines; sharing between people stays with
    collaboration in `specs/002-research-lifecycle`.
  - Access is limited to what TRCLI creates in the Drive, so it cannot browse or import
    existing Drive files.
  - Sync is on demand by default, with a reminder; automatic sync is optional.
  - Passphrase protection is optional and off by default.
  - Who registers TRCLI with Google is left to planning.
- This spec changes a promise of `specs/001-research-workspace` ("nothing leaves the
  machine except the identifier of an explicit lookup"): content now also leaves when the
  researcher has connected a service and runs a command that uses it. The base spec and
  its plan do not yet say so.
- FR-011 to FR-015, FR-018, FR-056, and FR-061 are security requirements and deserve
  explicit tests and a security review at planning time.
- SC-003 and SC-004 (transfer times) depend on the researcher's network and on the service;
  they are targets on "an ordinary home connection" and need a stated test condition.
- `trcli sync push|pull|status` were first sketched in the collaboration contract of
  `specs/002-research-lifecycle`; that contract now points here.
